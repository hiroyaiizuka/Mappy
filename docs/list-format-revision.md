# H2 とリストの形式

2026-09-16 の追加フィードバックに基づく受入条件。

```markdown
## 講座の構成

- はじめに
  - この講座で学ぶこと
  - 全体の流れ
- 絞る
  - 注意を絞る
    - シングルタスク
    - [[参考ノート]]
  - タスクを絞る
- 回復する
  - ![[図.svg]]
```

- H2 がルート、リストのインデントが親子関係となる。H6 の制限を受けない。
- Enter／Tab、改名、削除、並べ替え、親変更も同じ原文のリスト範囲へ反映する。
- リスト内の本文・画像は継続行のインデントを維持する。コード・コメント・引用内の記号をノードと誤認しない。
- 既存の複数段の見出し形式を引き続き読める。閲覧では変換しない。変換は明示操作とし、Undo で戻せる。
- 原文の構造を安全に保てない変換は理由を示して中止し、暗黙に内容を削除しない。
- 通常マップも直角の接続線と縦の幹で表現し、ルート・第一階層の間隔を広げる。
- `[[` の候補は Markdown 以外の Vault ファイルも含む。PNG／SVG の拡張子を保ち、`![[` では画像埋め込みを維持する。

検証: CRLF、本文保持、コード・コメント、重複名、深いリスト、Editor／Vault の既存保存経路、Undo、Markdown 側からのインデント変更、画像候補を自動テストと専用 Vault で確認する。実機の結果は `artifacts/` に記録する。
