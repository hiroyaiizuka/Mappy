# Mappy

Obsidian の Markdown を、マインドマップとしても編集するためのプラグイン開発プロジェクトです。

**現在は専用テスト Vault で試用するプロトタイプです。** H2 と箇条書きからのマップ／タイムライン表示、Markdown との分割・切り替え、ノードの編集、リンク・画像、frontmatter によるマップ識別、Excalidraw への挿入を実装しています。従来の見出し階層も維持します。実装の存在と受入条件の達成は分けて扱い、モバイル、日本語 IME の実入力、性能や長時間利用の確認は継続します。

## 開発

Node.js は `.nvmrc` のバージョンを使用します。

```sh
npm ci
npm run check
```

`check` はメタデータ検証 → lint → テスト → 型検査 → production build → 配布物検証を実行します。Markdown の解析・原文差分、保存と競合、レイアウト、ズーム、DOM の操作も自動テスト対象です。Obsidian のモックを使った成功は実機の成功として扱いません。

```sh
npm run dev               # ビルド監視
npm run test:watch        # テスト監視
npm run test:coverage     # 現在のテスト対象のカバレッジ
npm run harness:prepare   # 初回専用。既知の fixture を初期化する
npm run harness:preflight # ビルド成果物と検証 Vault の一致を確認
```

`dist/mappy/` に `main.js`、`manifest.json`、`styles.css` を生成します。`dist/build-info.json` は検証用のハッシュ記録です。公開や既存 Vault へのインストールは行いません。

試用中は `harness:prepare` を再実行せず、[更新手順](docs/harness.md#試用中の更新)で配布物3ファイルだけをコピーします。試用中の Markdown と添付ファイルを上書きしないでください。

任意で `npm run hooks:install` を実行すると、このリポジトリの pre-commit に同じ品質ゲートを設定できます。CI の定義は `.github/workflows/check.yml` にあります。

## 試作版の使い方

Markdown を開き、コマンドパレットから「マインドマップを開く」または「マインドマップと Markdown を並べる」を実行します。後者は左にマップ、右に標準エディタを置きます。キャンバスを全面に広げ、レイアウト切り替えは左下、Markdown 表示・分割は右上、ズームは右下の浮かせた操作 UI から利用します。

ルートは H2、その下は箇条書きのインデントで階層を作ります。項目の最初の行がノードのテキストになり、別のタイトル欄は不要です。

```markdown
## 講座の構成
- はじめに
  - この講座で学ぶこと
- 回復する
  - 睡眠
    - [[睡眠ノート]]
  - ![[図.png]]
```

文書直下の見出しが H2 だけ、または見出しがない場合はリスト形式になります。H1・H3 など H2 以外の見出しがある文書は、従来の見出し階層として表示します。旧形式を変える場合は、右クリックの「リスト形式に変更」またはコマンド「現在のマップをリスト形式に変更」を実行します。変換は明示操作で行い、マップの Undo で戻せます。既存本文の箇条書きが新しいノードを増やすなど、構造を保持できない変換は拒否します。

通常マップは余白のある直角線で接続し、タイムラインは横軸に第一階層、下位の枝を上下交互に表示します。最上位ノードが一つならそれを表示ルートにし、複数ならファイル名の表示用ルートでまとめます。

| 操作 | 方法 |
| --- | --- |
| 兄弟／子を追加 | ノード選択中に Enter／Tab。その場で空のテキストを入力 |
| テキスト編集 | F2 またはダブルクリック。Enter で確定、Escape で取り消し |
| 子を続けて追加 | テキスト編集中に Tab で確定して子を追加 |
| リンク・添付候補 | テキスト編集中に `[[` または `![[`。候補がある間の Enter／Tab は候補選択を優先 |
| 折りたたみ | Space または枝の分岐点にカーソルを合わせて現れる丸い −。閉じると非表示の子孫数を表示 |
| 本文・リンク編集／画像追加 | ノードの右クリックメニュー |
| 元に戻す／やり直す | マップ上で Cmd/Ctrl+Z／Cmd/Ctrl+Shift+Z または右クリック |
| 表示を移動／拡大縮小 | 背景ドラッグ・スクロール／ピンチ・修飾キー付きスクロール・右下のボタン |
| マップ ⇄ Markdown | コマンド「マップと Markdown を切り替え」。同じ leaf で往復し、Markdown 側は選択ノードの行へ移動 |

### マインドマップを作る

コマンド「新しいマインドマップを作成」は、Obsidian の新規ノート保存先に H2 ルートを持つファイルを作ります。既存の通常ノートは、コマンドまたはファイルの右クリックにある「このノートをマインドマップ化」を実行してからマップで開けます。明示操作で frontmatter に YAML の真偽値 `mappy: true` を書き、この値を持つノートだけを Mappy が扱います。

```markdown
---
mappy: true
mappy-layout: timeline
---
## 講座の構成
- はじめに
```

通常マップでは `mappy-layout` を省略します。左下でタイムラインを選ぶと `mappy-layout: timeline` を自動保存し、次に開いたときもタイムラインに戻ります。通常マップへ戻すとこの任意キーを削除します。切り替えで本文は変更しません。「このノートのマインドマップ化を解除」は `mappy` と `mappy-layout` を削除し、本文を保ったまま Markdown に戻します。

以前の版が書いた `mappy-layout` だけのノートは、自動ではマップとして開きません。「このノートをマインドマップ化」を実行すると以前のレイアウトを引き継いで `mappy: true` を追加します。「マップと Markdown を切り替え」で Markdown にした leaf は、同じノートを開き直しても Markdown のままです。既定のホットキーは登録しないので、Obsidian の設定で割り当ててください。

### Excalidraw に載せる

[Excalidraw プラグイン](https://github.com/zsviczian/obsidian-excalidraw-plugin)が有効なとき、次の 3 通りで使えます。

| 方法 | 結果 |
| --- | --- |
| `mappy: true` の `.md` を **Option（Alt）を押しながら**キャンバスへドロップ | マップを Excalidraw のネイティブ要素（矩形・テキスト・線・画像）として挿入。1 グループにまとまり、ルートは元ノートへのリンクを持つ |
| コマンド「現在のマップを Excalidraw の図面に挿入」 | 直前にアクティブだった図面へ、現在のレイアウトと折りたたみのまま挿入 |
| Excalidraw の「Insert interactive frame」（Ctrl／Win: Shift+Ctrl を押してドロップ） | `mappy: true` のノートは、生きた Mappy のビューとして枠内に表示・編集できる |

修飾キーなしや Excalidraw の挿入ダイアログは既定のまま使えます。`mappy: true` のノートを「as embeddable」または「as image」で追加した場合は、新しく作られた Mappy 埋め込み要素だけ外枠を透明にします。ネイティブ要素として挿入したマップは元ノートと同期しないスナップショットです。

保存元は通常の `.md` と添付ファイルです。本文は保持し、マップではノードのテキストと本文内のリンク・画像を表示します。リスト項目の本文編集は、最初の子リストより前の継続本文を扱います。子リストの後に書いた親の文章も保存範囲には保持しますが、本文編集画面では直接編集しません。

ノード内の入力は専用 textarea であり、Obsidian 標準エディタそのものではありません。独自の候補 UI でノートの名前・パス・別名に加え、PNG・SVG・PDF など Vault 内の添付ファイルも選べます。`![[` で始めた入力は埋め込みの `!` を保持します。PDF のプレビューや注釈機能は含みません。

リストには見出し由来の6階層制限を設けません。従来の見出し形式のみ H6 が上限です。番号付きリストとタスクリストは原文を保持し、ノード化しません。標準エディタと完全に共通の Undo 履歴と、リンク補完の全機能は未対応です。マップの履歴はファイルごとに保持し、Markdown 側や外部からの変更を検出すると破棄します。最新の検証条件・結果・未実施項目は `artifacts/` の実行記録で確認します。

## 開発時の扱い

名称・ID `mappy`、作者表記、最低対応バージョン `1.8.7` は開発用です。最小バージョンを含む対応環境全体の確認と公開名の重複確認は未完了です。`isDesktopOnly: false` はモバイル互換を目指す設計方針であり、動作保証ではありません。

公開ライセンスは未選択です。現在は `UNLICENSED` とし、権利を留保しています。製品機能の実装・検証後、公開前に確定します。
